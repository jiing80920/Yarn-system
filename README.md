# 用紗量管理

託工用紗量、各機台用紗計算、領紗提醒、預估完工時間與統整表格。
單一網頁（`index.html`），不需要安裝、不需要伺服器，資料存在使用者自己的瀏覽器。

## 檔案說明

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 主程式（所有功能都在這一個檔案） |
| `manifest.json`、`icon-*.png`、`apple-touch-icon.png`、`favicon.png` | 網頁圖示與「加入主畫面」設定 |
| `.nojekyll` | 告訴 GitHub Pages 直接原樣發佈 |

## 部署到 GitHub Pages

1. 登入 GitHub，按右上角 **+** → **New repository**。
2. Repository name 取名，例如 `yarn-system`，選 **Public**，按 **Create repository**。
3. 在新的空 repository 頁面按 **uploading an existing file**，把這個資料夾**裡面的所有檔案**（包含 `.nojekyll`）拖進去，按 **Commit changes**。
   - 要上傳的是檔案本身，`index.html` 必須在 repository 的最上層，不要多包一層資料夾。
4. 進入 **Settings** → **Pages**。
5. **Source** 選 **Deploy from a branch**，**Branch** 選 `main`、資料夾選 `/ (root)`，按 **Save**。
6. 等 1～2 分鐘，頁面上方會出現網址：

   ```
   https://<你的帳號>.github.io/yarn-system/
   ```

之後要更新程式，只要在 repository 重新上傳新的 `index.html`（覆蓋同名檔案）並 Commit，約一分鐘後網址就會是新版。

## 頁面組成

| 分頁 | 內容 |
| --- | --- |
| 託工用紗量 | 一、託工單（入庫盤頭、預排機台、每碼用紗量、機台比對）；二、託工單匯整 |
| 機台用紗設定 | 各機台的生產設定、開機與預估完工、領紗記錄、已生產數量（手機有自訂數字鍵盤）、廠內庫存 |
| 生產完工計算機 | 直接內嵌「生產完工計算機」原頁面，需要連網才能載入（它使用網路上的 React 程式庫） |
| 統整表格 | 領紗提醒、相同品代＋批號統整、各機台明細、託工單與機台比對 |

**已生產數量連動**：「機台用紗設定」的已生產數量記錄、轉速、緯密（＝計算機的條數）、開機時間、盤頭長／織縮，會和「生產完工計算機」同一台機台的資料雙向連動，在任一邊新增、修改、複製、刪除，另一邊都會跟著更新，只要輸入一次。計算機的「效率」只存在計算機。連動資料存在同一個瀏覽器，不同裝置之間要靠雲端同步（機台頁的資料會同步，計算機本身的資料由機台頁帶入）。

## 手機與電腦共用資料（雲端同步）

資料會同步到你自己 GitHub 帳號下的**私人資料庫**，手機和辦公室電腦連到同一個資料庫，就能看到同一份資料。只需設定一次。

1. **建立私人資料庫**：GitHub → **+** → **New repository**，名稱例如 `yarn-data`，一定要選 **Private**，並勾選 **Add a README file**，按 **Create repository**。
2. **建立存取權杖（Token）**：GitHub 右上頭像 → **Settings** → 最下方 **Developer settings** → **Personal access tokens** → **Fine-grained tokens** → **Generate new token**。
   - **Repository access** 選 **Only select repositories**，只選 `yarn-data`。
   - **Permissions** → **Repository permissions** → **Contents** 設為 **Read and write**，其他都不要開。
   - 有效期限選最長，並記得到期前重新建立。
   - 建立後**立刻複製** `github_pat_...` 開頭的那串字，離開頁面就看不到了。
3. **在網頁連線**：打開用紗量管理，點右上角 **☁ 未連線**，填入 GitHub 帳號、資料庫名稱 `yarn-data`、Token，按 **連線並同步**。
4. **第二台裝置**：在另一台設備重複第 3 步（Token 可以用同一個，也可以另外建一個）。第二台如果本機是空的，會直接載入雲端資料。

同步方式：

- 修改資料後約 2 秒自動上傳；每 60 秒、切回網頁時也會檢查雲端有沒有新資料。
- 兩邊都改過、內容不同時，會跳出視窗讓你選「使用雲端版本」或「使用這台版本」，沒選的那份會被取代。
- 離線時照常使用，連線後會自動補同步。
- 正在輸入時不會背景更新，避免打到一半被蓋掉。
- 如果資料庫是公開的，程式會拒絕連線，避免生產資料外洩。

安全提醒：Token 只存在你自己那台裝置的瀏覽器裡，請不要在公用電腦登入；Token 外洩時，到 GitHub 的 Token 頁面按 **Delete** 即可立刻作廢。

## 使用提醒

- **沒有連線雲端同步時，資料只存在各自的瀏覽器裡**，換電腦、換瀏覽器、清除瀏覽器資料或使用無痕模式，記錄都不會跟著走。
- 請定期到「統整表格」分頁按 **匯出備份**，把檔案存起來；換電腦或資料遺失時用 **匯入還原** 即可還原。
- 同一個 GitHub 帳號的各個網頁（例如 `yarn-calculator`）網址相同，但本程式的資料使用獨立的名稱儲存，不會互相覆蓋。
- 更新 `index.html` 後，既有的資料不會消失（資料在瀏覽器，不在程式裡）。

## 手機／平板

用 Chrome 或 Safari 開啟網址後，選「加入主畫面」，就能像 App 一樣開啟。介面以電腦螢幕為主要設計。
